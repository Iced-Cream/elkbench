# Template: an audio capture on an Analog Four MKII behind a level check, so a silent take stops
# the run instead of passing. The pattern's own trig plays T1 (grid recording: a key on the live
# screen adds no trig). The emulator's pass says nothing about sound: record the reference takes
# on the unit. Parameter reads (dump) of a voice go after the first hit: some values reach the
# voice only at note-on.
#
# The level check compares a short take with this plan's own reference take (level-ref.wav in its
# refs folder), recorded once on the unit from the same steps and kept. audio-compare fails on
# silence; audio-dropouts alone does not (silence has no dropouts). No plan step writes into refs:
# the first unit run records the takes with audio-record alone (a copy of this plan without the
# audio-compare lines), and the person copies level.wav and take.wav from its run folder into
# this plan's refs folder as level-ref.wav and take-ref.wav. The channel numbers are
# Overbridge's for the A4 MKII: read them from a recording's .channels.txt before the go.
format = 1
name = capture with level check
unit = a4
refs = refs/a4-capture-with-level-check
out = runs
audio-tools = C:/path/to/elkbench/audio
audio-driver = Elektron Analog Four MKII  # the ASIO driver audio-record records from
audio-python = py -3.14               # a Python with numpy and scipy for the audio checks (testplan
#                                     # uses the daemon's own otherwise): set it to yours
note = ~T SETUP active, unsaved: T1 trig on step 1; stopped

[start]
wait 3
tap NO
wait 0.5
tap NO
wait 0.5
tap NO
wait 1.0
# The start check: the run's own test project is active (the setup plan ran first in this run).
# The home title row (rows 0-7) of a new project reads K001:KIT 1 and BPM:120.0. The contrast: a
# fresh card has another project and kit active, so this check stops the run there; this plan's
# own pass comes from run_plan after the setup plan.
say contrast fresh: another project or kit is active, so the title row differs
expect-screen test-project-title 2 rows=0-7
# OSC1 steps between OSC1 (P 1/2) and NOISE (P 2/2), and a track key keeps the page, so OSC1 is
# entered from another page (FLTR): its first press then always opens P 1/2.
tap T1
wait 0.5
tap FLTR
wait 0.6
tap OSC1
wait 0.6
# then T1's OSC1 page 1/2, by its knob labels and dials (rows 8-63). The title
# bar names the page only for a moment before it goes back to the kit's name.
expect-screen t1-osc1-page 2 rows=8-63
# and the sequencer stopped (the stop square where the play indicator goes): PLAY on a playing
# pattern pauses it on the A4, and the setup's grid recording would run on a moving pattern
expect-screen stopped 2 rows=2-6 cols=119-125

[setup: one T1 trig on step 1, the pattern playing]
say proves setup: the sequencer starts T1 (a pattern trig, not a MIDI note)
tap RECORD
wait 0.6
tap 1
wait 0.3
tap RECORD
wait 0.6
tap PLAY
wait 1
# the play indicator only (a triangle playing, a square stopped): proves the precondition the take depends on
expect-screen playing 2 rows=2-6 cols=119-125

[level check (hardware)]
say proves works: T1 sounds at its reference level on its own channel (3) before any take
audio-record 3 level
audio-compare level-ref level 3

[take (hardware)]
say proves works: the take, compared with its reference
audio-record 10 take
audio-dropouts take 1,2
audio-compare take-ref take 1,2
tap STOP
wait 1
