# Template: build the run's own test project on a Rytm MKII (OS 1.74 + analoghealth) from CREATE NEW,
# and prove it. Copy it beside your plans and change only what the comments name. Rules behind it:
# docs/testing-practices.md, "Plan checker and templates".
#
# The new project comes from CREATE NEW (the LOAD PROJECT list's last row), which starts from nothing.
# SAVE PROJECT AS puts it into 121 and makes the saved copy active; loading 121 then proves it is
# active, and its home screen proves it is new. The active project comes from 121 afterwards, so a
# later run's LOAD asks only PROCEED, and the start check needs no active-project marker.
#
# Before this plan, the run backs up and clears the test slot (outside the plan for now):
#   data get /projects/121      (the backup, into the run's evidence folder)
#   data clear /projects/121
# List both in the go request as writes: "slot 121 (holds X at listing time: backed up and erased)".
# The turn in the second section makes the active project unsaved, and CREATE NEW then discards it
# (answered NO to the save): list that in the go request too.
format = 1

unit = rytm
refs = refs/setup-test-project        # this plan's own references: never share them with another plan
